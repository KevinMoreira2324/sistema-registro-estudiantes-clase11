## Descripción
Este proyecto es una aplicación sencilla desarrollada en Python que permite gestionar una lista de tareas desde la consola. El usuario puede añadir tareas, visualizar las tareas existentes y eliminar aquellas que ya no necesite.

## Objetivo
El objetivo de este proyecto es poner en práctica conceptos básicos de programación en Python, como variables, listas, estructuras de control, bucles, entrada de datos por teclado y manejo básico de errores.

## Funciones principales
- Mostrar la lista de tareas.
- Añadir nuevas tareas.
- Eliminar tareas existentes.
- Salir de la aplicación.

## Requisitos
Para ejecutar este proyecto es necesario disponer de:

- Python 3.x instalado.
- Un editor de texto o IDE (Visual Studio Code, PyCharm, etc.).
- Terminal o consola de comandos.

## Ejecución

### Windows 
 
```powershell 
python sistema_estudiantes.py 
``` 
 
### Linux 
 
```bash 
python3 sistema_estudiantes.py 
```
